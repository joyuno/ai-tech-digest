<div class="categories">

<div class="sub-tags">
<span class="sub-tag">#Reasoning Model</span>

기존 AI 에이전트는 주로 외부 모듈을 통해 기억 능력을 구현했지만, 파운데이션 모델 자체의 내재적인 기억 능력은 아직 충분히 탐구되지 않았습니다. 이 연구는 파운데이션 모델에 직접 기억 능력을 부여하는 '메티스(Metis)'라는 메모리 파운데이션 모델을 최초로 제안하며, 모델이 자체적으로 정보를 기억하고 활용하는 새로운 방향을 제시합니다.

<h3><a href="https://arxiv.org/abs/2607.28568" target="_blank">Frontis-MA1: Training an AI4AI Model towards Recursive Self-Improvement in Machine Learning Engineering</a></h3>







AI가 AI를 만드는 과정(AI4AI)을 스스로 개선하는 재귀적 자기 개선(RSI) 연구를 위해, 머신러닝 엔지니어링(MLE)을 구체적인 실험 환경으로 제시합니다. 이를 위해 OpenMLE라는 오픈소스 시스템을 구축하고, 그 위에서 메타 진화 에이전트 역할을 하는 Frontis-MA1 모델을 훈련시켜 AI의 자기 개선 능력을 연구합니다.

<h3><a href="https://huggingface.co/papers/2607.28624" target="_blank">PhiZero: A World Model Built Around Physical Language</a></h3>


<div class="categories">
<span class="category-tag"><i data-lucide="brain"></i> 모델/아키텍처</span> 
</div>




  


<div class="sub-tags">
<span class="sub-tag">#World Model</span> 
</div>


PhiZero는 '물리 언어(physical language)'를 중심으로 구축된 새로운 물리 세계 모델입니다. 이 모델은 픽셀 단위로 미래를 예측하는 대신, 세상의 상태 변화를 간결한 언어적 표현으로 학습하여 물리적 법칙을 명시적으로 다룹니다. 이는 인간이 언어로 세상을 이해하듯, 시각적 경험에서 물리적 구조를 추상화하여 더 체계적인 예측을 수행합니다.

<div class="item-meta">




<span class="meta-pill meta-author"><i data-lucide="user"></i> Shuyao Shang, Yuqi Wang, Ruopeng Gao</span>
</div>

</div>


<div class="digest-item" markdown="1">



<h3><a href="https://huggingface.co/papers/2607.28625" target="_blank">ACE-Data-0: Human-Centric Ambient Capture as Embodied Data Engine</a></h3>


<div class="categories">
<span class="category-tag"><i data-lucide="search"></i> 추론/검색</span> 
</div>




  


<div class="sub-tags">
<span class="sub-tag">#RAG</span> 
</div>


체화된 인공지능(Embodied AI) 개발은 인간의 시각, 행동, 소리 등 다중 감각 데이터를 통합적으로 포착하지 못하는 데이터 병목 현상을 겪고 있습니다. ACE(Ambient Capture Engine)는 실제 가정 환경에서 1인칭 시점, 전신 움직임, 사물 조작 등 인간의 모든 상호작용을 종합적으로 수집하는 인간 중심 데이터 엔진입니다. 이를 통해 기존의 파편화된 데이터 문제를 해결하고 완전한 인식-행동 데이터를 제공합니다.

<div class="item-meta">




<span class="meta-pill meta-author"><i data-lucide="user"></i> Yukang Cao, Haozhe Xie, Beichen Wen</span>
</div>
