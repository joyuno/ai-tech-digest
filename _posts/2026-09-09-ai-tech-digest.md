<div class="categories">
<span class="category-tag"><i data-lucide="brain"></i> 모델/아키텍처</span> 
</div>




  


<div class="sub-tags">
<span class="sub-tag">#Diffusion</span> 
</div>


LLM이 토큰을 순차적으로 생성하여 속도가 느린 자기회귀(autoregressive) 방식의 한계를 극복하기 위한 새로운 방법을 제시합니다. 이 연구는 확산(diffusion) 모델을 결합하여 기존 자기회귀 모델의 분포를 그대로 따르면서도 여러 토큰을 병렬로 생성함으로써, 성능 저하 없이 생성 속도를 크게 향상시킵니다.

<div class="categories">
<span class="category-tag"><i data-lucide="brain"></i> 모델/아키텍처</span> <span class="category-tag"><i data-lucide="wrench"></i> 학습/최적화</span> 
</div>




  

  


<div class="sub-tags">
<span class="sub-tag">#RLVR</span> <span class="sub-tag">#Distillation</span> 
</div>


RISE는 언어 모델의 성능을 스스로 개선하는 새로운 정책 증류(Policy Distillation) 기법입니다. 이 방법은 모델 자신의 학습 궤적을 기반으로 가상의 교사 모델을 구축하여, 외부 교사 모델의 한계나 분포 불일치 문제 없이 재귀적으로 성능을 향상시킵니다.
